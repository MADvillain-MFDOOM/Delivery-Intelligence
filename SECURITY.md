# Security

- Never submit credentials, API tokens, private keys, or production data.
- Use synthetic data for examples and issue reproductions.
- Report suspected exposed secrets privately to the repository maintainers; do not publish them in an issue or pull request.
- Public examples must not contain identifiable company, customer, or employee information.
- Repository maintainers may remove sensitive submissions immediately to protect people and systems.

If a secret is exposed, assume it is compromised: notify maintainers privately and rotate or revoke it through the owning system.
